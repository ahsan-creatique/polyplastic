Part Formation Line

Part_Formation_Line__c
Dynamic Columns
  • Part Reference RFQ_Part__c
    Master-Detail Parent Part (e.g. YFG 27MC)
  • Component Material Component_Material__c
    Text(80) Grill, Garnish LH, Logo...
  • Sequence / Order Sequence__c
    Number(3,0) 1, 2, 3, 4 (controls col position)
  • Total Internal Testing Cost Column_Total_Internal_Cost__c
    Roll-Up: SUM Internal Costing TOTAL COST cell
  • Total External Testing Cost Column_Total_External_Cost__c
    Roll-Up: SUM External Costing TOTAL COST cell
  • Column Grand Total Cost Column_Grand_Total_Cost__c
    Formula: Currency GRAND TOTAL row cell for this part

Testing Feasibility

Testing_Feasibility__c
Table Rows
  • Part Reference RFQ_Part__c
    Master-Detail Parent Part Header
  • Sr. No Sequence__c
    Number(4,0) 1, 2, 3...
  • Process Process__c
    Picklist MOLDING, PLATING, etc.
  • Type of Testing (LOT) Type_of_Testing__c
    Dependent Picklist RAW MATERIAL, BOPC, etc.
  • UOM UOM__c
    Text(10) Default: "NOS" UOM column
  • Row Total Quantity Row_Total_Quantity__c
    Roll-Up: SUM Feasibility Table Total column
  • Row Total Internal Cost Row_Total_Internal_Cost__c
    Roll-Up: SUM Internal Costing Total column

Testing Feasibility Detail

Testing_Feasibility_Detail__c
Matrix Cell (Junction)
  • Testing Row Testing_Feasibility__c
    Master-Detail Connects to Test Row
  • Part Formation Line Part_Formation_Line__c
    Master-Detail / Lookup Connects to Formation Line
  • Testing Quantity Quantity__c
    Number(8,0) Testing Feasibility Qty input
  • Internal Cost Internal_Cost__c
    Currency(14,2) Internal Costing INR input
  • External Cost External_Cost__c
    Currency(14,2) External Costing INR input
  • Total Cost Total_Cost__c
    Formula: Internal + External Cell sum

RFQ Part (Header)

RFQ_Part__c
Parent Header
  • Part Name Name
    Text(80) Header Material (e.g. YFG 27MC)
  • Total Internal Cost Total_Internal_Testing_Cost__c
    Roll-Up: SUM Overall Internal Testing Sum
  • Total External Cost Total_External_Testing_Cost__c
    Roll-Up: SUM Overall External Testing Sum
  • Grand Total Testing Cost Grand_Total_Testing_Cost__c
    Formula: Int + Ext Overall Grand Total
